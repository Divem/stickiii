# 快速记录产品需求

> 技术实现见：[整体架构与同步边界](../tech/architecture.md)

## 1. 产品定位

Desk Tabs 是一个跨窗口、低打扰的桌面随手记。用户不需要先打开某个应用、创建文件夹或决定内容应该放在哪里，只要按下快捷键，就能把当前想法、截图和文件先收进一个可靠的本地标签里。

产品的核心承诺是：**先记录，再整理；先保存在手边，再决定是否同步到其他系统。**

## 2. 目标用户与场景

- 工作中突然想到一件事，需要在会议、浏览网页或写代码时立刻记下。
- 临时收到一张图片、一个文件或一段文字，希望和当下的上下文放在一起。
- 想把一条记录继续整理到 Notion、飞书文档等长期知识库，但不想为了记录动作离开当前窗口。

## 3. MVP 范围

### 当前可用

- 全局快捷键 `Command/Ctrl + Shift + Space` 唤起一个约 440×390 的置顶便签窗口，并优先显示在当前鼠标附近。
- 窗口可以自由拖动、缩放、最小化和关闭；关闭后可再次由快捷键唤起，窗口仍保持置顶并可跨桌面显示。
- 当前便签直接可输入；其他便签、删除、设置、附件和同步入口在悬停工具栏或点击后的菜单中出现。
- 记录标题、正文和本地自动保存。
- 通过系统文件选择器添加图片和文件；图片在窗口内预览，文件可以交给系统打开。
- 中英文界面切换。

### 接口已预留

- Notion 和飞书同步连接器。
- 每条记录的同步状态和当前选中的目标连接器。
- 远端文档 URL、字段映射、认证状态的扩展位置。

### 下一阶段

- OAuth / Personal Token 授权与安全存储。
- 一条记录到一个远端文档或数据库条目的映射。
- 记录、附件、远端页面之间的增量同步。
- 冲突提示、失败重试、手动重试和同步历史。
- 从当前窗口复制选中文本、截图或网页链接的快捷捕获入口。
- 标签颜色、置顶、归档、Markdown / 富文本和提醒。

## 4. 交互原则

1. **打开快**：快捷键唤起后直接聚焦输入区，不弹出复杂配置。
2. **保存稳**：本地保存是第一成功标准，网络失败不能影响记录。
3. **内容完整**：文字、图片和任意文件都能放在同一条记录里。
4. **用户可控**：外部同步必须由用户选择目标并主动点击；第三方写入结果要能看见。
5. **窗口友好**：窗口可以当作桌面边角的小本子，也可以拉大做整理。

## 5. 成功标准

- 用户从其他应用切换到记录窗口的动作不超过一次快捷键。
- 输入停止后，记录在本地自动落盘；重启应用后仍可见。
- 关闭记录窗口不会丢失已保存内容。
- 未配置第三方服务时，用户能明确知道如何配置，而不会看到虚假的“已同步”。
