# 快速记录产品需求

> 技术实现见：[整体架构与同步边界](../tech/architecture.md)

## 1. 产品定位

贴贴便签是一个跨窗口、低打扰的桌面随手记。用户不需要先打开某个应用、创建文件夹或决定内容应该放在哪里，只要按下快捷键，就能把当前想法、截图和文件先收进一个可靠的本地标签里。

产品的核心承诺是：**先记录，再整理；先保存在手边，再决定是否同步到其他系统。**

## 2. 目标用户与场景

- 工作中突然想到一件事，需要在会议、浏览网页或写代码时立刻记下。
- 临时收到一张图片、一个文件或一段文字，希望和当下的上下文放在一起。
- 想把一条记录继续整理到 Notion、飞书文档等长期知识库，但不想为了记录动作离开当前窗口。

## 3. MVP 范围

桌面底座为 Tauri：macOS 使用系统 WKWebView，Windows 使用 WebView2。Windows 的构建、体积和实际运行验收单独记录。应用本体不包含浏览器运行环境，完整 Windows 离线安装包可另行携带 WebView2。

### 当前可用

- 每条便签可通过更多菜单或便签列表“独立窗口打开”，重复操作恢复并聚焦原窗口。独立窗口固定显示一条便签，保留编辑、预览、附件、主题、AI、飞书同步、置顶与关闭；全局配置仍从主窗口进入。独立打开后，主窗口保留列表与只读预览，显示“前往窗口”；关闭独立窗口后恢复主窗口编辑。
- 不同便签可同时编辑，同一便签只允许一个窗口编辑。关闭独立窗口先保存，“回到主窗口编辑”保存后关闭独立窗口并定位原便签；保存失败保留窗口和草稿。主窗口隐藏不影响其他窗口。正常退出等待所有窗口保存成功，并记住仍打开窗口的位置、尺寸和置顶状态；再次启动恢复，断开显示器后移回可见工作区。独立便签删除需先完成该窗口的保存和操作。详见 [独立便签窗口方案](../tech/independent-note-windows.md)。

- 全局快捷键 `Command/Ctrl + Shift + Space` 唤起一个约 440×390 的便签窗口，并优先显示在当前鼠标附近。窗口在前台时再次按下才隐藏；窗口在其他应用后方或已最小化时先恢复并聚焦。
- 全局快捷键包含唤起/隐藏、新建、上一条和下一条便签四个动作，用户可以在设置中重新录入快捷键。新的上一条 / 下一条默认使用 `Command/Ctrl + Alt + Left/Right`，避开常用文本选择组合；已有保存的快捷键继续保留，可通过“恢复默认快捷键”更新。
- 带快捷键的操作在悬停 Tips 中展示实际键位：顶部加号、列表加号、更多菜单的新建与空状态入口显示新建快捷键；翻页箭头保留相邻标题并显示上一条 / 下一条快捷键；主窗口关闭按钮提示唤起 / 隐藏快捷键。自定义或恢复默认后提示同步更新，按 macOS / Windows 展示键位；独立窗口关闭不显示主窗口唤起快捷键。
- 主窗口可以自由拖动、缩放、最小化和隐藏；关闭时隐藏，可再次由快捷键唤起。顶部“置顶”按钮打开后才保持在其他窗口上方并跨桌面显示，关闭后恢复普通窗口层级。
- 当前拥有编辑入口的便签直接可输入；主窗口顶部保持单行，包含带保存状态角标的 Logo、便签标题、新建便签加号、小眼睛开关、便签列表、固定位置的置顶图标和更多操作。点击加号新建便签；小眼睛在编辑与预览之间切换，预览时高亮，不显示模式文字，悬停提示下一步动作。未保存时在 Logo 右上角显示小星星，保存成功后隐藏星星，保存失败时星星变红。悬停 Logo 查看具体保存状态。标题过长时省略，不挤动右侧按钮。
- 底部保持单行，包含更新时间、打开飞书文档、AI 润色、附件和飞书同步按钮；设置入口与当前版本的同步状态持续可见。其他底栏操作在窗口有焦点且鼠标移入时显示，鼠标移出后隐藏；键盘焦点进入底部按钮时也可显示。AI 操作菜单展开期间保持底栏可见，鼠标从箭头移向菜单时不会隐藏。首次使用显示截图粘贴、文件拖入和底部操作提示，关闭后不再显示。隐藏与显示不改变正文高度；窄窗口中同步和润色按钮仅显示图标，保留操作提示。
- 点击便签列表按钮一次即可展开并聚焦搜索框，再次点击关闭；macOS 主窗口失焦后，首次点击同时激活窗口并执行按钮操作。激活窗口产生的短暂 blur/focus 过渡不会撤销刚刚打开的菜单。顶部列表、底部页码和列表内独立打开按钮在鼠标释放时立即执行，并避免同一按压重复触发；键盘操作保留 click 行为。菜单内点击标题、空白等不可聚焦区域不会关闭；焦点移向菜单触发按钮时由按钮完成切换，避免失焦和点击重复改变状态。点击菜单外部、焦点移到其他控件或按 `Escape` 时关闭弹出菜单，窗口失焦时关闭便签列表与更多操作。设置草稿在切换应用后保留，方便复制文档链接或凭据。同步结果独立显示在底部上方，鼠标移出底栏后仍可看见；失败提供重试入口，提示可主动关闭。
- 在一个文本框里连续记录，不区分标题和正文；第一行自动作为窗口栏和便签列表中的标题，第一行为空时显示“未命名记录”。停止输入约 520ms 后自动保存；新建、切换与主动退出前保存最新草稿，保存等待期间的新输入也会留下。保存失败时保留草稿并显示“重试保存”。
- 浏览未修改的便签不会改变修改时间和导航顺序。便签列表可搜索正文，显示高亮命中片段以区分同名便签；↑↓ 选择、Enter 打开、Escape 返回正文，较多结果分批显示。未输入内容或添加附件的空草稿不落盘，反复新建时复用空草稿。
- 删除确认包含便签标题，删除后选择相邻便签并提供 8 秒撤销；删除最后一条后显示空草稿，撤销时恢复原便签。附件移除也提供 8 秒撤销，正文或附件继续修改后失效，避免覆盖新输入。删除撤销仅保留当前会话最近一次操作。
- 多条便签以纸页方式浏览：两侧与正文共用连续背景，鼠标移入且窗口有焦点时才显示轻微的上一页 / 下一页箭头和底部页码，移出或窗口失焦后隐藏；键盘聚焦翻页或页码按钮时也可显示。默认只保留正文，不绘制三张独立卡片，不显示相邻页的正文和边框。点击边缘即可翻页，悬停可查看相邻便签标题，支持连续快速翻页；翻页动画按方向轻轻掀起当前页，系统开启“减少动态效果”时直接切换。底部页码可点击打开搜索列表；快捷键和列表切换共用翻页行为。沿用会话内的稳定顺序，首尾循环，只有一条便签时隐藏两侧箭头与页码。切换前保存最新输入，失败留在当前页；各便签继续保留编辑模式、光标和滚动位置。
- 首次进入记录直接聚焦正文。编辑 / 预览切换保留编辑框与撤销历史；切换便签时保留各自的编辑模式、光标选择范围和滚动位置。
- 窗口内按 macOS `Command + E` / Windows `Ctrl + E` 切换编辑与预览，主窗口和独立便签均支持；小眼睛按钮的悬停提示显示快捷键。设置、搜索等菜单、中文输入法组合输入、按键重复及当前没有编辑归属时不触发切换。
- 通过系统文件选择器添加图片和文件；图片直接显示在笔记正文中，按可用宽高等比例缩小，完整显示单张图片并为上下文字留出空间；窗口缩放时自动调整，小图不放大，正文字号保持原样。编辑时可在图片前后继续输入，点击可打开原图，悬停可移除；普通文件保留底部附件卡片。粘贴图片按当前光标位置插入，预览模式和文件选择器追加到末尾；旧图片附件也显示在正文末尾。添加附件期间显示忙碌状态；选择文件期间继续输入或切换便签，不会将附件加到错误的便签或覆盖新输入。
- 主窗口与独立便签支持截图/图片粘贴及多文件拖入正文，编辑和预览模式均可使用；拖入显示高亮提示。一次最多 20 个，单个不超过 20 MB；部分失败保留成功的附件。普通文字粘贴不变，导入保留原便签最新输入并自动保存。文件夹暂不支持，详情见 [截图粘贴与文件拖入](../handover/attachment-capture.md)。
- 更多操作菜单按图标、文字与内边距自动定宽，图标与文字靠左排列；中英文切换后文字保持单行。主窗口菜单提供“退出应用”：等待所有窗口完成保存及已触发的附件导入、同步和 AI 润色后退出；保存失败则取消退出。主窗口右上角关闭按钮表示隐藏，独立窗口的关闭按钮保存后关闭该窗口。
- Markdown 源码编辑与预览切换，支持标题、强调、列表、待办、表格、引用、代码块、链接和网络图片；标题取第一行的纯文本。预览保留输入时的普通换行，空行仍区分段落，切回编辑时保留原始内容。Markdown 标题需独占一行，井号后加空格，例如 `## 二级标题`。
- Markdown 列表回车续写，空项回车退出；Command/Ctrl + B 切换选中文字的加粗；预览可以直接勾选待办并写回源码。列表和加粗操作保留编辑器原生撤销，代码围栏中的列表文本不自动续写。
- 飞书云文档同步：可选择每条笔记创建独立文档，或填写文档链接，将每条笔记追加为独立章节；重复同步更新原位置，冲突时先确认。
- 中英文界面切换；顶部应用名称在中文下显示“贴贴便签”，英文下显示“Stickiii”。
- 一键 AI 润色当前便签：在设置中填写兼容 Chat Completions 的 API 地址、模型名称和自己的 API Key；Key 保存在系统凭据库。润色改善表达、语法和标点，并要求保留原意、语言、Markdown 和首行标题结构；只发送当前文字，不上传附件。润色按钮右侧的小箭头提供 AI 翻译、AI 扩写和 AI 解读，四种操作都只使用固定的产品提示词；翻译按中英文互译，其他语言译为中文，扩写和解读不能编造原文之外的事实。四种操作都先展示原文、优化后和差异，由用户选择保留原文、替换或另存。小窗口显示行内差异，宽度达到 640 px 时并排对照；新增有背景与下划线，删除有背景与删除线。采纳后自动保存，可从更多菜单重新查看对比或撤销；继续编辑正文后失效。请求期间可以输入或切换便签，结果只作用于原便签且不覆盖新输入。未配置时打开模型设置，失败保留原文并说明原因。使用与验收见 [AI 润色](../handover/ai-polish.md)。
- 首次创建本地笔记库时预置两条可编辑便签，分别介绍贴贴便签的产品定位与使用方法，并提供联系邮箱 `imyuanwen@gmail.com`；它们与普通便签一样可以修改或删除，删除全部后下次启动保持空库；保留数据目录的重新安装尊重原删除选择，使用指南可从更多菜单随时打开。
- 无边框极简视觉，每条便签可以独立选择极简白、雾灰、鼠尾草绿、天空蓝、暖杏、淡紫或夜墨主题；背景透明度是全局设置，可在 40%–100% 之间以 2 个百分点为步长调整，切换便签时保持不变，正文与关键提示保持清晰。中英文切换收在设置中，标题栏只保留必要操作。顶部按钮命中区域为 28×30px，最窄窗口将最小化操作收进更多菜单。
- 窗口周围保留柔和的系统阴影，圆角边缘有一圈淡色细线，在白色背景下也能辨认窗口范围；夜墨主题使用浅色细线。

## 4. 交互原则

AI 模型配置提供“测试连接”，无需先保存即可验证当前填写的地址、Key 和模型是否返回有效回复，并显示耗时。测试使用固定短文本，不上传便签或附件，不修改已保存配置；修改字段后清除旧测试结论。润色时模型原样返回只表示本次没有改动，界面提供重试和模型设置入口，不据此判断“内容无需调整”。

AI 成功提示将撤销操作放在关闭按钮左侧，与状态文字同处一行，5 秒后自动收起；提示关闭或收起后，撤销仍保留在更多菜单中。继续编辑正文时立即清除该提示与对应撤销记录。

主题、语言和所有窗口背景透明度保留在快捷设置中；AI、飞书与快捷键进入较大、可滚动的设置面板。面板限制键盘焦点在内部，关闭后返回正文。AI 地址、模型与飞书普通配置字段的未保存草稿保留在当前主窗口会话；关闭设置后重新打开不回填输入中的密钥，浏览器存储不保存密钥。飞书“检查已保存配置”只检查认证和追加目标编辑权限，创建模式的实际写入权限仍需同步验证。

1. **打开快**：快捷键唤起后直接聚焦输入区，不弹出复杂配置。
2. **保存稳**：本地保存是第一成功标准，网络失败不能影响记录。
3. **内容完整**：文字、图片和任意文件都能放在同一条记录里。
4. **用户可控**：外部同步必须由用户选择目标并主动点击；第三方写入结果要能看见。
5. **窗口友好**：窗口可以当作桌面边角的小本子，也可以拉大做整理。

## 5. 成功标准

- 用户从其他应用切换到记录窗口的动作不超过一次快捷键。
- 输入停止后，记录在本地自动落盘；重启应用后仍可见。
- 关闭记录窗口不会丢失已保存内容。
- 未配置第三方服务时，用户能明确知道如何配置，而不会看到虚假的“已同步”。

## 6. 同步范围与验收

当前飞书同步文字和 Markdown 排版。本地图片上传为图片块，本地文件上传为附件块，Markdown 网络图片以链接保留；界面在同步前说明范围。失败不能显示“已同步”，也不能影响本地记录。

实现与模拟接口测试不等于真实租户验收。真实写入需用户根据模式填写协作者邮箱或目标文档链接、开通飞书应用权限后主动触发，操作见 [飞书与 Markdown 使用及验收](../handover/feishu-markdown.md)。
