# 飞书与 Markdown 使用及验收

## 当前可用

- 一份 Markdown 内容，第一行纯文本自动作为便签标题。
- 点击“编辑 / 预览”切换，支持标题、强调、列表、待办、表格、引用、代码块、链接和网络图片。
- 本地预览保留普通换行，连续三行文字不会挤成一行；空行区分段落，代码块保留原有换行。切回编辑时源码保持不变。二级标题写成单独一行的 `## 标题`；行内的 `##标题` 作为普通文字显示。
- 飞书同步支持两种模式：每条便签创建独立文档，或将多条便签追加到指定文档，每条便签形成独立章节。
- 追加模式以第一行作为章节标题，再次同步同一便签更新原章节，保留目标文档标题、原有内容和其他便签章节。
- 底部提供飞书一键同步按钮；Notion 远端接口尚未接入，当前隐藏同步按钮和设置入口。
- 同步后可打开飞书文档；独立文档模式给配置的协作者邮箱授予编辑权限。追加模式使用目标文档现有权限。
- 权限不足、网络异常、云端冲突、分享失败等均显示明确状态；本地记录继续保存。

## 配置飞书

1. 在飞书开放平台创建并发布企业自建应用，获取 App ID 和 App Secret。
2. 在应用权限管理中申请“创建及编辑新版文档”“文本内容转换为云文档块”“添加云文档协作者”以及云空间素材上传所需的云空间读写权限，完成管理员审批并发布新版本。
3. 确保应用与协作者账号互相可见，协作者属于应用可访问的组织范围。
4. 在贴贴便签右下角“设置 → 飞书”选择同步模式并填写 App ID / Secret。修改已保存配置时可将 Secret 留空，继续使用原 Secret。
5. 选择“每条笔记创建新文档”时，填写自己的飞书账号邮箱；选择“追加到同一篇文档”时，粘贴目标文档链接，并在该飞书文档中通过“更多 → 添加文档应用”给本应用编辑权限。追加模式无需协作者邮箱，也不会修改目标文档的分享权限。
6. 编写便签，直接点击底部“飞书”按钮。成功后点击“打开飞书文档”查看结果。

填写配置时，点击面板内的说明或空白处、切换输入框，或切到其他应用复制链接和凭证，设置面板与已输入内容会保留。点击“保存配置”后才保存；仍可通过“取消”“返回”、Esc、再次点击设置按钮或点击面板外的便签区域退出。

独立文档模式使用应用身份在应用云空间根目录中创建文档，并给配置邮箱添加编辑权限。修改邮箱会添加新的协作者，不会撤销原有协作者权限；需要撤销时在飞书文档的分享面板管理。

追加模式支持飞书 `docx` 链接和底层为 `docx` 的 `wiki` 链接。Wiki 链接需要应用具有知识节点阅读权限，并先解析实际文档 ID；界面保留用户填写的原始链接。切换模式或目标链接会分别保存同步位置，切回后继续更新原有文档或章节。

## 当前边界

- 飞书同步为本地到云端的手动更新，不会把云端修改自动拉回本地。独立文档模式检测整个文档冲突；追加模式仅检测当前笔记章节，确认覆盖也只更新该章节。修改其他章节不阻断同步。
- 网络 Markdown 图片以链接保留；便签中的本地图片会上传为飞书图片块，其他本地附件会上传为可下载的文件块。渲染层只发送附件 ID，Rust 从当前便签的受管目录读取字节，不发送本地路径。暂未实现多维表格目标和新建知识库节点。
- Notion 远端写入、OAuth 用户授权、自动同步、双向合并和面向用户的同步历史尚未实现。
- 追加模式每个章节最多 1000 个文档块。章节被部分删除或拆开时停止更新，不猜测索引范围删除其他内容。请求中断时保留未完成的章节事务，重试使用原始幂等标识恢复写入。
- 远端更新采用先写新内容、再删除旧内容的顺序。中途失败可能暂时保留新旧两份内容，再次同步仍使用同一文档并恢复为当前内容。
- 创建文档请求结果未知时停止再次创建，并显示“创建结果未确认”。当前尚无界面恢复入口，需先确认飞书侧结果后人工恢复本地关联；不能直接反复重试创建。

## 真实租户验收

1. 用一条包含标题、列表、待办、表格和代码块的测试便签点击同步。
2. 打开返回链接，确认自己有编辑权限、内容和排版完整。
3. 修改便签再次同步，确认链接不变、没有重复文档或重复内容。
4. 在飞书修改文档，再同步应提示冲突；取消后云端内容保持原样。
5. 切换到追加模式，选择已有文档，依次同步两条便签；确认每条形成一个章节，文档原有内容保留。
6. 修改其中一条再次同步，确认只更新该章节，章节不重复且其他内容不变；修改另一个云端章节不应阻断本笔记同步。
7. 切换目标文档后再切回，确认复用原章节。确认界面不显示 Notion 同步按钮和设置入口。
8. 验证失败提示时，不把本地“已保存”当作云端“已同步”。
