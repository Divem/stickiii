# 操作与性能优化交接

本次优化针对保存中切换丢字、浏览改变顺序、预览破坏编辑位置、同步结果被悬停隐藏，以及全量 JSON 写入开销。

## 当前可用

- 统一保存队列和最新草稿 flush；新建、切换与主动退出等待最新修改落盘，失败保留草稿并提供重试。
- 浏览未修改便签不写盘、不改时间；会话中的便签导航顺序稳定。
- 空草稿不落盘，反复新建复用空草稿；首次记录聚焦正文。
- 编辑 / 预览保留 textarea；各便签保留模式、光标与滚动位置。
- 同步提示独立于悬停底栏，失败有重试入口；Notion 明确提示尚未开放。
- 正文搜索与分批列表；顶部标题只在首行改变时重新解析。
- 附件导入忙碌提示、失败反馈和移除入口；异步结果绑定原便签并合并最新附件。Rust 复制在工作线程执行，不持有整个 Store 锁。
- BufWriter 缓冲序列化，继续执行 fsync 与原子替换；Rust 保存命令从窗口线程移到阻塞工作线程。
- 顶部按钮 28×30px；最窄窗口将最小化收进更多菜单。背景透明度不再降低正文和关键反馈的透明度。
- 新的上一条 / 下一条默认组合为 Command/Ctrl+Alt+Left/Right；已有设置保留。
- 历史便签按纸页切换：正文与边缘共用连续背景，取消独立纸页卡片、边框和相邻正文；鼠标移入且窗口有焦点时显示两侧的轻微箭头和底部页码，移出或失焦后隐藏，失焦立即生效。键盘聚焦相应按钮时可显示；隐藏时不接收鼠标点击，显示与隐藏不改变正文尺寸、选区和滚动。悬停箭头可查看相邻便签标题；底部页码打开原有搜索列表。切换成功后播放 280ms 的定向掀页动画，连续操作可立即中断上一段动画，编辑框不因动画重新挂载。翻出页保留原主题；只有一条便签时隐藏边缘与页码，减少动态效果时直接切换。仍沿用保存队列与首尾循环顺序，保存失败不翻页。

## 验证

契约测试新增延迟保存后的最新输入、排队保存合并、失败重试、删除与迟到保存、退出时后台草稿落盘、空草稿跳过和附件 / 主题修改。Rust 测试覆盖未修改保存不改时间、不写盘、重启可读。

2026-10-03 验证结果：

- 类型检查、55 项 TypeScript 契约测试、12 项 Rust 测试及 React / Rust 生产构建通过。
- 浏览器使用隔离便签和模拟桌面桥：连续下一条为 A → B → C → A，零写盘；300ms 保存延迟期间的新文字留下；光标 80–90 和滚动 700px 在预览往返后保持；实际键盘撤销仍有效。搜索、独立同步提示、保存重试、附件导入期间的新正文、附件移除，以及取消退出后重试成功均通过。
- macOS WKWebView 使用独立应用标识、数据目录与凭据服务，实际执行 React 事件、Tauri IPC 和 Rust 存储：12 项原生检查通过，涵盖首次焦点、输入落盘、预览、光标滚动、300ms 延迟切换、空草稿、未修改导航、退出失败恢复、置顶、附件路径约束、未配置同步和增删。额外在自动保存等待结束前立即退出，进程正常退出且磁盘含最新文字。
- 全局快捷键与多显示器的实际操作，以及真实文件选择器的人工操作，没有在这次隔离原生检查中验收。

2026-10-03 纸页切换补充验证：类型检查、56 项契约测试和 React 生产构建通过。浏览器使用独立模拟桌面桥与测试笔记，验证两侧点击、首尾循环、动画期间连续 8 次切换、浏览零写盘、页码搜索入口、300ms 保存等待期间继续输入、翻回恢复选区与滚动、预览模式保留、失败停留当前页及重试后继续翻页。440×390 与 320×260 排版已检查，减少动态效果、跨主题翻页、中英文和单条便签也已检查。本次翻页补充验证没有在 macOS WKWebView 或 Windows 安装版中执行。

同日简约样式调整：类型检查和 React 生产构建通过。浏览器使用模拟桌面桥检查默认隐藏、聚焦窗口移入后显示、移出后隐藏、模拟 blur 事件后立即隐藏，以及恢复焦点但鼠标仍在窗口外时继续隐藏。显隐前后正文尺寸、选区与滚动相同；两侧按钮保持可点击，浏览零写盘；键盘聚焦翻页与页码搜索入口正常。已查看 440×390 的默认与悬停截图、320×260 的悬停截图；本次样式检查不覆盖原生窗口的焦点验收。

直接调用当前 storage.rs，macOS arm64、release 模式、每种规模 5 次保存取中位数；正文每条约 2KiB，图片场景使用合成 Base64 预览。原实现数值来自同日本机检查，系统负载与文件缓存会影响数值。

| 数据规模 | 原实现 | 本次实现 |
| --- | ---: | ---: |
| 1,000 条纯文本 | 63.9ms | 10.5ms |
| 5,000 条纯文本 | 303.4ms | 18.5ms |
| 1,000 条，另含 20 份约 1MiB 原图对应的预览 | 87.0ms | 19.2ms |

这些是存储函数耗时，包含克隆、序列化与原子落盘，不含 Tauri IPC 和界面刷新；不能用于声明整体唤起延迟或 Windows 性能。
