# AI 润色使用与验收

## 当前可用

卡片底部的“AI 润色”一次优化当前文字，按钮右侧的小箭头还提供“AI 翻译”“AI 扩写”和“AI 解读”。四种操作都先展示优化前后对比，保留原文，由用户选择替换原文、另存便签或保留原文。设置中的“AI 模型 → AI 润色”提供 API 地址、模型名称和 API Key；未配置时点击任一操作会打开该表单。接口支持 OpenAI Chat Completions 格式，可填写 OpenAI、DeepSeek 或其他兼容服务，也可使用回环地址的本地兼容服务。仅提供 Anthropic Messages 或 Responses 接口的服务尚未接入。

## 配置与操作

1. 打开卡片底部设置，进入“AI 模型 → AI 润色”。
2. 填写服务商的基础地址，例如 `https://api.openai.com/v1` 或 `https://api.deepseek.com`，以及账户可用的模型 ID。模型名称以服务商当前文档为准。
3. 填写自己的 API Key，可先点击“测试连接”：使用表单当前地址、模型和 Key 发送一次固定的短请求，成功显示模型及耗时，失败说明鉴权、地址、网络或响应问题。测试不保存配置，不读取或发送便签；修改字段后旧测试结果清除。Key 留空时只可使用同一地址已保存的 Key，更换地址需重新填写。
4. 点击“保存配置”后，API Key 保存在 macOS Keychain / Windows Credential Manager，不回显。完整的 `/chat/completions` 地址也会规范化为基础地址。
5. 在便签中输入文字，点击“AI 润色”执行润色；点击右侧箭头可选择翻译、扩写或解读。菜单展开期间底栏保持可见，鼠标移向菜单时不会自动隐藏；选择操作、点击正文、按 Escape 或窗口失焦时关闭。润色按钮与箭头之间不使用分割线，箭头通过背景和文字深浅区分默认、悬停与展开状态。翻译默认中文与英文互译，其他语言译为中文。请求期间可以继续编辑或切换便签；同一时间只发起一个请求。
6. 结果默认显示差异，可切换“原文”“优化后”“差异”。点击“替换原文”才写回并保存；“保留原文”放弃结果，“另存便签”保留原便签并生成副本。采纳后提示右侧提供撤销，成功提示 5 秒后自动消失；关闭或收起提示后，仍可从更多菜单查看前后对比或撤销。继续编辑正文时清除已采纳的对比及撤销记录。若生成期间修改了文字，结果不能替换新内容，但四种操作的结果都可另存为新便签。失败提示保留重试入口。
7. 模型返回原文时提示本次没有改动，不解释为“内容无需调整”；可重新执行对应操作或进入模型设置。润色要求改善措辞、语序、冗余、语法与标点；翻译要求保持语义与语气；扩写和解读要求区分事实与推断并禁止编造。所有操作都保留 Markdown、链接、代码和待办勾选状态，实际结果仍取决于所选模型。
8. 在模型配置里点击“清除配置”删除保存的 Key 与模型信息。

四种 AI 操作都会将当前文字发送给配置的服务，不上传附件，也不自动同步飞书文档。提示要求保留 Markdown、链接、代码和待办勾选状态；实际结果由所选模型决定。正文为空时无法执行；输入超过 64 KiB UTF-8 时提示缩短内容。鉴权失败、额度不足、超时、返回空内容或不完整回复时保留原文。

## 前后对比

- “原文”使用此次请求的原文快照，“优化后”显示返回结果；两者使用只读 Markdown 预览，待办不能勾选修改。
- “差异”展示完整的 Markdown 源码，新增内容带绿色背景和下划线，删除内容带红色背景和删除线，不只依赖颜色区分。代码、链接地址、空白与标记变化也能看见。
- 小窗口显示行内差异，可以滚动查看；窗口宽度达到 640 px 时，差异自动改为原文和优化后两列，共用滚动区。底部操作保持可见，320×260 的中英文按钮均在一行内。
- 比较先对齐行，再细化为 Unicode 字符，避免拆开 Emoji；大范围改写超出计算预算时按较大段落展示替换，保留两份完整内容，不截断或丢弃文字。
- 采纳后重新打开对比，底部可撤销或另存。对比只保留当前窗口会话最近一次 AI 修改，继续修改正文后失效；尚未实现持久化版本历史或逐段采纳。

## 验证边界

契约测试验证应用结果、撤销、后续输入保护、删除保护、后台便签保存和具名桌面桥。Rust 测试验证系统凭据的公开配置脱敏、同地址 Key 复用、地址校验、响应完整性，以及通过本地 HTTP 服务器验证真实请求、认证头、错误分类和禁止重定向；另验证未保存配置测试不会写入凭据库、不能向新地址复用旧 Key、测试请求不携带便签，以及原样回复返回 `unchanged`。界面验收使用模拟桌面桥和模拟回复，不等于真实服务商调用。

真实模型调用需用户填写有效 Key、API 地址及可用模型后主动点击；未使用用户付费凭据进行验收。Windows 凭据库与窗口运行需在 Windows 单独验收。
