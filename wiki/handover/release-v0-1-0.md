# v0.1.0 预发布交接

发布页：[Stickiii v0.1.0](https://github.com/Divem/stickiii/releases/tag/v0.1.0)。源码提交到 `Divem/stickiii` 的 `main` 分支，安装包通过 Release 分发，不写入 Git 源码目录。

## 本次内容

- 正文直接显示本地图片，支持图片前后输入、保存恢复、移除与打开原图；按笔记可用宽高等比例缩小，并给上下文字留出空间。
- 完善便签列表首次点击、菜单焦点、编辑/预览快捷键提示与 AI 菜单交互。
- 飞书手动同步本地图片和文件附件；修复带查询参数的创建回执未登记媒体块，以及把媒体绑定限制为文档根块的问题。只允许当前任务已登记的媒体块与匹配的素材类型。
- 启动与普通编辑只读取脱敏配置，主动使用 AI/飞书或查看旧配置时才读取系统凭据，避免启动反复触发钥匙串授权。
- 同步全部现有文档、测试及宣传发布证据。

## 安装包

| 文件 | 用途 |
| --- | --- |
| `Stickiii_0.1.0_macos_arm64.dmg` | macOS Apple Silicon 安装包，内含应用与 Applications 链接 |
| `Stickiii_0.1.0_macos_arm64.app.zip` | 完整应用包的 ZIP 版本 |
| `SHA256SUMS.txt` | 安装包与验证记录的 SHA-256 校验值 |
| `release-validation.json` | 源码提交、构建架构与检查结果 |

此次只有 macOS arm64 产物。应用使用 ad-hoc 签名，完整包签名检查与 DMG 校验通过；Developer ID 签名、公证、Windows 与 Intel Mac 安装包尚未交付。构建与打包不替换本机已安装应用。

## 验证与边界

2026-10-04：类型检查、80 项前端契约、Rust 编译检查、37 项 Rust 测试、生产构建与 `package:mac` 通过。没有真实 AI 调用或飞书租户写入。

图片适配的上一轮浏览器验收覆盖三种窗口、四种图片比例和编辑/预览模式，共 24 个组合；macOS 隔离窗口的两个阶段通过，记录见 [正文图片交接](attachment-capture.md)。发布前再次执行 `test:window-smoke`，连续两次因系统锁屏、原生点击辅助程序无法取得焦点而停止；没有删除、绕过或把该断言改为通过。这一轮不宣称系统点击验收通过，解锁后可按原命令重新执行。

真实租户同步、系统钥匙串弹窗、Windows 运行与公证分发仍需相应环境验收。二进制校验通过不等于这些真实环境验收已完成。
