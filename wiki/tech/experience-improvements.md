# 体验细节优化与验收

本轮按体验分析的顺序实施，保留本地优先、受限桌面桥和用户主动同步边界。以下能力已在源码实现；本轮交付范围是源码，不包含发布、安装新版本或调用真实租户/付费模型。

## 步骤与完成判据

1. 搜索：正文命中片段、高亮、方向键选择、Enter 打开、Escape 回到正文；同名便签可区分。
2. AI 回退：提示收起后仍能撤销最近 AI 修改；后续正文修改使撤销失效。四种 AI 操作先对比原文、结果与差异，可替换或另存便签。
3. 删除与附件：确认显示标题，删除停留相邻便签并提供短时撤销；附件移除可撤销，不能覆盖后续输入。
4. 入口：设置保持可见，首次提供粘贴/拖入提示，熟悉后保持简洁。
5. 配置：主题与透明度留在浮层，复杂配置用较大面板；普通字段草稿不因关闭丢失，Secret 不写浏览器存储。
6. 同步：持续显示当前版本状态、同步进度和错误；配置可主动检查认证与目标权限，冲突可先打开云端内容。
7. Markdown：列表续写/空项退出、加粗快捷键、预览勾选待办；代码块和普通换行不受影响。
8. 首次使用：仅真正首次启动生成介绍，空库重启不重新生成；帮助可重新打开指南。
9. 小窗口：提高辅助字号，区分隐藏主窗口/关闭便签，标明主题与透明度的作用范围。

## 验证与状态

### 当前可用

| 步骤 | 实际行为与验证 |
| --- | --- |
| 搜索 | 显示正文命中前后片段，保留原大小写；同名记录能看见上下文。方向键循环选取，Enter 打开，Escape 回到正文。浏览器验证双结果选择与同名片段，契约测试覆盖片段边界。 |
| AI | 四种操作先展示原文、结果与差异，用户采纳后才保存。关闭提示或 5 秒收起后仍可从更多菜单查看对比或撤销，后续输入清除已采纳的对比和撤销。结果可保留原文、替换或另存；生成期间新输入会禁止替换，另存保留原文与附件。浏览器使用模拟模型验证，原生测试验证副本保存与来源权限。 |
| 删除和附件 | 确认显示标题，删除后选择相邻便签，8 秒内可恢复最近删除。最后一条删除后留下未落盘空草稿，恢复时不增加多余空便签。附件移除 8 秒内可撤销，正文修改、导入或再次移除会废止旧撤销。Rust 校验删除快照、单次恢复与过期；浏览器验证最后一条恢复和到期。 |
| 入口提示 | 设置入口一直可见；首次展示粘贴截图、拖入文件及底部 AI/飞书提示，主动关闭后保留偏好。其他底部工具保持原有按焦点和悬停出现的规则。 |
| 设置 | 快捷设置保留主题、语言、全局透明度。AI、飞书、快捷键使用较大面板，背景不可交互，Tab 在面板内循环。普通字段草稿只保留当前主窗口会话；密钥不保存到浏览器，关闭设置后重新打开不回填输入中的密钥。320×260、440×390 模拟界面检查了可滚动面板、关闭、草稿恢复和测试结果。 |
| 同步 | 持续显示当前版本同步状态。关闭错误提示不抹掉失败；正文或附件变更使较早成功回执不能标记新版本已同步。冲突可先打开云端、明确覆盖或保留；冲突后再编辑会拦截直接覆盖。浏览器模拟验证这些流程，Rust fixture 验证只读认证检查请求。 |
| Markdown | 列表回车续写、空项退出、Command/Ctrl + B 加粗及预览待办勾选。围栏内文本不续写；输入法组合输入、Shift+Enter 与原有普通换行不受影响。契约测试覆盖源码操作，浏览器验证连续加粗、列表和原生撤销；macOS WKWebView 也通过列表续写、原生撤销、连续加粗和待办勾选回归。 |
| 初次启动 | 只有没有笔记库文件的首次初始化才生成介绍。已有空库、删除全部后的重启、空的旧库迁移保持为空；Rust 测试覆盖。更多菜单的使用指南是独立只读面板，可随时打开，不新增用户便签。 |
| 小窗口 | 提高辅助字号，冲突操作分行并保留间距；主窗口关闭提示为隐藏，独立窗口提示为保存并关闭。主题标明仅当前便签，透明度标明所有窗口；中英文、夜墨主题与最小窗口已做视觉检查。 |

### 原生和安全边界

- 新增 `restore_note`、`create_note_copy`、`check_feishu_connection`，同时注册命令、权限与桌面桥。恢复和配置检查只允许受信主窗口；副本命令使用运行时登记的便签归属校验，独立窗口不能复制别的便签。
- Rust 保留最近删除快照 10 秒，界面提供 8 秒入口，给本地调用留出余量；不接受渲染层任意恢复内容。恢复后解除保存队列的删除标记。
- 副本由 Rust 读取原便签的附件与主题，只替换文字并生成新 ID，不继承远端文档关联。密钥继续使用系统凭据库，不向渲染层返回。
- 飞书配置检查只读取已保存凭据。创建模式只验证认证；追加模式验证 Wiki 解析、DocX 读取和 `permissionMember.Auth` 的 `action=edit` 权限。获取令牌需要认证 POST，之后只发送 GET，不创建文档或上传素材。修改配置字段会清除旧结论。
- 同步结束比较登记的正文和附件快照，并把保存的便签状态随所有结果返回；因此失败与并发新修改可以持续呈现。Notion 仍为未实现，入口保持隐藏。
